# EMD с равномерным ядром: Python и Jupyter Notebook

Откройте `emd_kernel_demo_ru.ipynb`: блокнот содержит весь код реализации,
описание формул, графики, численные результаты и проверки `assert`.
Импорт соседнего файла `kernel_emd.py` для запуска блокнота не требуется.

## Запуск

Для зафиксированных зависимостей нужен Python 3.11 или новее.
Проверка вычислений выполнена на Python 3.12.14.

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell вместо предыдущей строки:
# .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
jupyter lab emd_kernel_demo_ru.ipynb
```

Выберите **Kernel → Restart Kernel and Run All Cells**. Установка пакетов
не выполняется самим блокнотом. Зафиксированы версии четырёх библиотек,
на которых получены сохранённые результаты; JupyterLab служит интерфейсом.
Проверка при подготовке: последовательное исполнение всех Python-ячеек
в одном пространстве имён CPython с сохранением вывода и графиков в формате
блокнота 4.5. В данном окружении отдельный сервер JupyterLab не запускался.

## Что реализовано

1. Центрированное равномерное усреднение; устойчивое двойное усреднение.
2. Фиксированные масштабы, прямое просеивание и точная периодическая FFT-форма.
3. Начальная оценка длины по экстремумам и автоматический внешний цикл.
4. Экспериментальный замороженный профиль `L[n]`; адаптация с передискретизацией по фазе.
5. Аналитический сигнал, фаза, мгновенная частота и локальный осциллятор.
6. Прямая квадратура при заданной положительной огибающей.
7. Условные интегральные матрицы, синтез по интервальной частоте и локальная проекция.
8. Частотная плотность с сохранением фазы и отдельным учётом неопределённых значений.

## Использование модуля

```python
import numpy as np
from kernel_emd import decompose_fixed, analytic_features

fs = 900.0
n = np.arange(3600)
x = np.cos(2*np.pi*100*n/fs) + 0.5*np.cos(2*np.pi*25*n/fs)
result = decompose_fixed(x, lengths=[9, 36], iterations=8, boundary="wrap")
mode1 = analytic_features(result.modes[0], fs, trim=2)
frequency_hz = mode1.frequency
oscillator = mode1.oscillator
restored = result.reconstruct()
```

Это итеративная фильтрация IF/RIF по статье, а не классическое EMD со сплайнами.
В двойном варианте каждый базовый вектор имеет веса `1/L`, но эффективный
фильтр имеет треугольные веса и длину `2L-1`. В фазовой конструкции равные
веса применяются на фазовой сетке. Точное сохранение суммы с остатком
не доказывает правильность физических компонент. В блокноте явно указано,
где масштабы заданы заранее, где оценены по данным и какие области исключены
из проверки частоты. Нули амплитуды, шум и смешение мод требуют диагностики.
